# ToDoApp

An iOS 15+ SwiftUI application optimized for iPhone, providing a comprehensive to-do list experience with Core Data + CloudKit sync, notifications, widgets, Siri Shortcuts, and sharing.

## Features
- Create, edit, categorize, prioritize, and complete tasks with optional reminders.
- Tag-based filtering, search, and customizable task views.
- Core Data persistence with iCloud synchronization via CloudKit.
- Push notification reminders for due tasks.
- Share/export task lists and maintain backups.
- Widgets for quick glances and Siri Shortcuts for voice-first workflows.
- Automated unit, UI, and performance testing targets.
